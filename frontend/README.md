Este é um projeto do *frontend* do Sins of Macunaíma. Feito em:
- Node.js
- Next.js
- Phaser.js

## Configurando
1. Instale as depêndencias necessárias com `npm install`.
2. Use `npm run build` para criar arquivos de build.
3. Finalmente, rode `npm run dev` para a versão de debug e `npm run start` para a versão de produção.
